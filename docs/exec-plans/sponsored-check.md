# Sponsored-Check: UK Visa Sponsorship Job Checker — UK Sponsored Check

## Goal

A lightweight Chrome extension that tells a UK job seeker within two seconds whether a job posting sponsors work visas — via a non-intrusive banner — with zero setup, zero friction, and no manual update steps. Keyword signals in the post take precedence; a locally cached index of the GOV.UK sponsor register provides the company-level fallback.

## Status

Blocks 1–8 complete and shipped (v0.9.10). Block 9 (Chrome Web Store submission) pending.

## Decision log (key entries)

- Keyword verdict takes precedence over directory; negatives checked before positives.
- Universal injection (`http://*/*`, `https://*/*`) — accepted broad permission for root-fix detection; store justification required (SC-006 knowingly traded).
- Banner always shows on job pages, always resolves (no stuck loading).
- Company off-register → Not sponsored, but only when a company was actually matched; otherwise Couldn't determine (never fabricate).
- Name matching errs toward amber: false red is worse than false amber.
- Pipeline: GitHub Actions daily → GOV.UK register (no API; ~10 MB CSV, daily updates) → name→rating index (Skilled Worker route only) → committed; extension pulls weekly; up-to-a-week staleness accepted.
- No build tooling; vanilla JS, stdlib Python, zero npm deps.
- Rejected: LLM analysis, search-results list view, backend server, mobile.
- Icon: soft-rounded Union Jack (generated by scripts/make_icons.py).
